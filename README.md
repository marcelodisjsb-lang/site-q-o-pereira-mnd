
# Clique Aqui

Um site simples e interativo, desenvolvido com HTML, CSS e JavaScript.

## Funcionalidades

- Tela inicial com a mensagem "clique aq".
- Botão interativo para avançar.
- Segunda tela com a mensagem "fds".
- Animação de transição.
- Design minimalista em preto e branco.

## Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript

## Como acessar

O site pode ser acessado pelo navegador após sua publicação no GitHub Pages.
